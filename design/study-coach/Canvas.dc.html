3Study Coach · plan view redesign
Design notes and assumptions
Organized around "what do I study next": the hero is the next session with the single solid blue button. Plan management (Push to Schedule, Refine inputs, Export in overflow) lives in the header row; Push is outlined so the hero Start stays the one primary. Pushed state shown in 3b as a green-dot confirmation with a quiet Update link. The progress bar reuses the Grade Hub cushion-bar language: blue done, light blue remaining, amber for sessions behind schedule in 3c. In the behind state, Catch up is an amber-bordered action inside the amber block; Start session remains the page primary since the student still starts the next session either way. Topics strip sits above the weeks with amber markers on struggle-added topics and carries the Struggle Tracker link, so the tracker no longer occupies a card row. Numbers: 12 sessions × 45 min = 9.0 hrs; mid-plan 5 done leaves 5.25 hrs; behind state 4 done, 7 expected by day 9 of 18, so 3 behind, 6.0 hrs left. Nav chrome shown on 3a and 3e only. Trust line cut entirely per brief.
