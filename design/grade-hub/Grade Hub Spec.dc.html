1 · Grade math

For a course with components i, each with weight_i (percent, summing to 100) and, if graded, grade_i (0–100):
earned = Σ graded (grade_i × weight_i / 100) — points banked.
lost = Σ graded ((100 − grade_i) × weight_i / 100) — points gone forever.
remaining = Σ ungraded (weight_i) — points still on the table.
maxAchievable = 100 − lost = earned + remaining
neededAvg = (targetCutoff − earned) / remaining × 100 — the hero number.
cushion = maxAchievable − targetCutoff — cushion is defined against the max still-achievable grade, not against 100.
Target is reachable iff cushion ≥ 0. If cushion < 0, show the impossible state (2b): hero number becomes maxAchievable, shortfall is −cushion.
Worked example (2a): Midterm 93 at 30% → earned 27.9, lost 2.1, remaining 70, maxAchievable 97.9. A+ cutoff 90.0 → neededAvg 88.7, cushion 7.9. Segments 27.9 + 2.1 + 62.1 + 7.9 = 100.
Worked example (2b): Midterm 68 at 30%, Quizzes 78 at 15% → earned 32.1, lost 12.9, remaining 55, maxAchievable 87.1. Target 90 → cushion −2.9: short 2.9, residual lost 10.0. Segments 32.1 + 55.0 + 2.9 + 10.0 = 100.
All-graded (2d): remaining 0 → bar is earned 92.4 + lost 7.6.
