All 26 AP Physics 1 flashcards

The full deck as text, grouped by unit. Each answer lists the CED topic and code it comes from.

Unit 1: Kinematics (10-15%)

Scalars vs. vectors?
Scalars have magnitude only. Vectors have both magnitude and direction.Topic 1.1, CED code 1.1.A.1
What is average velocity?
The displacement of an object divided by the time interval in which that displacement occurs.Topic 1.2, CED code 1.2.B.2
What is special about projectile motion?
It has zero acceleration in one dimension and constant, nonzero acceleration in the other dimension.Topic 1.5, CED code 1.5.B.2

Unit 2: Force and Translational Dynamics (18-23%)

What is translational equilibrium?
A configuration of forces such that the net force exerted on a system is zero.Topic 2.4, CED code 2.4.A.2
What is apparent weight?
The magnitude of the normal force exerted on a system.Topic 2.6, CED code 2.6.C.1
How does static friction behave?
It adopts whatever value and direction are needed to prevent an object from slipping or sliding on a surface.Topic 2.7, CED code 2.7.B.2
What is centripetal acceleration?
The component of an object's acceleration directed toward the center of its circular path.Topic 2.9, CED code 2.9.A.1

Unit 3: Work, Energy, and Power (18-23%)

What is work?
Energy transferred into or out of a system by a force exerted on that system over a distance.Topic 3.2, CED code 3.2.A.1
Can a system made of a single object have potential energy?
No. A single-object system can only have kinetic energy.Topic 3.4, CED code 3.4.A.1
What is power?
The rate at which energy changes with respect to time.Topic 3.5, CED code 3.5.A.1

Unit 4: Linear Momentum (10-15%)

What is impulse?
The average force exerted on a system multiplied by the time interval during which the force is exerted.Topic 4.2, CED code 4.2.A.2
When is a system's total momentum constant?
When the net external force exerted on the system is zero.Topic 4.3, CED code 4.3.B.2
What defines an elastic collision?
The system's initial kinetic energy equals its final kinetic energy.Topic 4.4, CED code 4.4.A.1

Unit 5: Torque and Rotational Dynamics (10-15%)

What is the lever arm?
The perpendicular distance from the axis of rotation to the line of action of the force.Topic 5.3, CED code 5.3.A.2
When is a system's rotational inertia at a minimum?
When the axis of rotation passes through the system's center of mass.Topic 5.4, CED code 5.4.B.1
When does a system's angular velocity change?
When the net torque exerted on it is not zero.Topic 5.6, CED code 5.6.A.1

Unit 6: Energy and Momentum of Rotating Systems (5-8%)

When is a system's total angular momentum constant?
When the net external torque exerted on the system is zero.Topic 6.4, CED code 6.4.B.2
What is a rolling system's total kinetic energy?
The sum of its translational and rotational kinetic energies.Topic 6.5, CED code 6.5.A.1
Does friction dissipate energy in ideal rolling without slipping?
No.Topic 6.5, CED code 6.5.B.2

Unit 7: Oscillations (5-8%)

When does simple harmonic motion result?
When the restoring force is proportional to the displacement from equilibrium.Topic 7.1, CED code 7.1.A.2
How are period and frequency related?
T = 1/f.Topic 7.2, CED code 7.2.A.1
Does changing the amplitude change the period of simple harmonic motion?
No.Topic 7.3, CED code 7.3.A.2

Unit 8: Fluids (10-15%)

What is pressure?
The perpendicular component of force per unit area. Pressure is a scalar.Topic 8.2, CED code 8.2.A.1-2
What is the buoyant force?
A net upward force exerted on an object by a fluid.Topic 8.3, CED code 8.3.B.1
What does the continuity equation describe?
Conservation of mass flow rate in incompressible fluids (A1v1 = A2v2).Topic 8.4, CED code 8.4.A.2
What does Bernoulli's equation describe?
Conservation of mechanical energy in fluid flow.Topic 8.4, CED code 8.4.B.2
