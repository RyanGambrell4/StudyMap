All 31 AP Biology flashcards

The full deck as text, grouped by unit. Each answer lists the CED topic and code it comes from.

Unit 1: Chemistry of Life (8-11%)

What do the hydrogen bonds between adjacent polar water molecules result in?
Cohesion, adhesion, and surface tension.Topic 1.1, CED code 1.1.A.2
What are sulfur, phosphorus, and nitrogen used to build?
Sulfur is used in building proteins. Phosphorus is used in phospholipids and nucleic acids. Nitrogen is used in nucleic acids.Topic 1.2, CED code 1.2.A.1
What is hydrolysis?
A chemical reaction that cleaves covalent bonds, breaking molecules into smaller molecules. Adding water to the bond between monomers breaks it.Topic 1.3, CED code 1.3.A.1
What are the structural components of a nucleotide?
A five-carbon sugar (deoxyribose or ribose), a phosphate, and a nitrogenous base.Topic 1.6, CED code 1.6.A.1

Unit 2: Cells (10-13%)

Why do surface area-to-volume ratios matter to a cell?
They affect a biological system's ability to obtain nutrients, eliminate wastes, acquire or dissipate thermal energy, and exchange chemicals and energy with the environment.Topic 2.2, CED code 2.2.A.1
What causes the selective permeability of the plasma membrane?
The membrane's hydrophobic interior.Topic 2.4, CED code 2.4.A.1
What is passive transport?
The net movement of molecules from high concentration to low concentration.Topic 2.5, CED code 2.5.A.2
How did mitochondria and chloroplasts originate?
They evolved from once free-living prokaryotic cells via endosymbiosis.Topic 2.10, CED code 2.10.A.1

Unit 3: Cellular Energetics (12-16%)

How do enzymes facilitate reactions?
Enzymes are proteins that act as biological catalysts by lowering the activation energy of a reaction.Topic 3.1, CED code 3.1.A.1
When does denaturation of an enzyme occur?
When the protein structure is disrupted by a change in its environment, which may change its function or efficiency.Topic 3.2, CED code 3.2.A.1
What does photosynthesis use, and what does it make?
It uses carbon dioxide, water, and light energy to make carbohydrates and oxygen.Topic 3.4, CED code 3.4.A.1
What does glycolysis produce?
ATP (from ADP and inorganic phosphate), NADH (from NAD+), and pyruvate.Topic 3.5, CED code 3.5.B.1

Unit 4: Cell Communication and Cell Cycle (10-15%)

How does cell signaling begin?
When a receptor protein in a target cell recognizes a chemical messenger, the ligand.Topic 4.2, CED code 4.2.B.1
How does negative feedback maintain homeostasis?
By reducing the initial stimulus.Topic 4.4, CED code 4.4.A.1
What are the stages of the cell cycle?
Interphase (G1, S, G2), mitosis, and cytokinesis.Topic 4.5, CED code 4.5.A.1
What can disruptions to the cell cycle result in?
Cancer or apoptosis (programmed cell death).Topic 4.6, CED code 4.6.B.1

Unit 5: Heredity (8-11%)

How do mitosis and meiosis compare?
Both use a spindle apparatus to move chromosomes. They differ in the number of cells produced and in the genetic content of the daughter cells.Topic 5.1, CED code 5.1.B.1
Which genes do Mendel's laws of segregation and independent assortment apply to?
Genes on different chromosomes.Topic 5.3, CED code 5.3.A.1
What is phenotypic plasticity?
Individual genotypes producing different phenotypes because environmental conditions influence gene expression.Topic 5.5, CED code 5.5.A.1

Unit 6: Gene Expression and Regulation (12-16%)

Purines vs. pyrimidines?
Purines (G, A) have a double-ring structure. Pyrimidines (C, T, U) have a single-ring structure.Topic 6.1, CED code 6.1.B.1
In which direction is new DNA synthesized?
5' to 3'.Topic 6.2, CED code 6.2.A.1
How can operons in prokaryotes be regulated?
In an inducible or a repressible system.Topic 6.5, CED code 6.5.B.1
What does gel electrophoresis do?
It separates DNA fragments by size and charge.Topic 6.8, CED code 6.8.A.1

Unit 7: Natural Selection (13-20%)

How is evolutionary fitness measured?
By reproductive success.Topic 7.1, CED code 7.1.B.1
What is Hardy-Weinberg equilibrium?
A model for describing and predicting allele frequencies in a non-evolving population.Topic 7.5, CED code 7.5.A.1
Sympatric vs. allopatric speciation?
Sympatric speciation happens in populations with geographic overlap. Allopatric speciation happens in geographically isolated populations.Topic 7.10, CED code 7.10.C.1
Punctuated equilibrium vs. gradualism?
Punctuated equilibrium is rapid evolution after a long period of stasis. Gradualism is slow evolution over hundreds of thousands to millions of years.Topic 7.10, CED code 7.10.B.1

Unit 8: Ecology (10-15%)

How do energy and matter move through ecosystems?
Energy flows, while matter and nutrients cycle through biogeochemical cycles.Topic 8.2, CED code 8.2.B.2
What is carrying capacity?
The sustainable abundance of a species that can be supported by the ecosystem's total available resources.Topic 8.4, CED code 8.4.A.1
Why are keystone species important?
Their effects are disproportionate to their abundance. When they are removed, the ecosystem often collapses.Topic 8.6, CED code 8.6.B.1
Name two human impacts the CED lists as driving extinctions.
Biomagnification and eutrophication.Topic 8.7, CED code 8.7.C.1

College Board, AP Biology Course and Exam Description, Effective Fall 2025. Unit titles, exam weights and topic numbers come from this document.
