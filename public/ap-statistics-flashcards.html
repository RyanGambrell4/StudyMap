All 20 AP Statistics flashcards

The full deck as text, grouped by unit. Each answer lists the CED topic and code it comes from.

Unit 1: Exploring One-Variable Data and Collecting Data (20-30%)

Why are the median and IQR called resistant?
Outliers do not greatly affect them, if at all.Topic 1.7, CED code 1.7.F.1
What does a standardized score (z-score) measure?
The number of standard deviations a value falls above or below the mean.Topic 1.9, CED code 1.9.D.1
What is bias in a sampling method?
A systematic error that makes a statistic consistently larger or smaller than the parameter.Topic 1.12, CED code 1.12.A.1
What allows a cause-and-effect conclusion in an experiment?
Random assignment of treatments to experimental units.Topic 1.13, CED code 1.13.D.1

Unit 2: Probability, Random Variables, and Probability Distributions (15-25%)

When are events A and B independent?
When knowing whether A occurred does not change the probability of B.Topic 2.7, CED code 2.7.A.1
What are the mean and standard deviation of a binomial random variable?
Mean = np. Standard deviation = the square root of np(1 - p).Topic 2.10, CED code 2.10.B.1
What does the empirical rule say?
About 68% of the values in a normal distribution lie within 1 standard deviation of the mean, about 95% within 2, and about 99.7% within 3.Topic 2.11, CED code 2.11.C.1
What is a sampling distribution?
The distribution of a statistic's values for all possible samples of a given size from a population.Topic 2.12, CED code 2.12.A.1

Unit 3: Inference for Categorical Data: Proportions (15-25%)

When is an estimator unbiased?
When, on average, it does not underestimate or overestimate the population parameter.Topic 3.1, CED code 3.1.A.1
For a given sample, what happens when you increase the confidence level?
The critical value increases, so the margin of error increases.Topic 3.4, CED code 3.4.C.1
What is a Type I error?
Finding convincing statistical evidence that the alternative hypothesis is true when it is not.Topic 3.8, CED code 3.8.A.1
What is the probability of a Type I error?
The significance level, alpha.Topic 3.8, CED code 3.8.B.1
What does the chi-square statistic measure?
The distance between observed and expected counts, relative to the expected counts.Topic 3.14, CED code 3.14.A.1

Unit 4: Inference for Quantitative Data: Means (10-20%)

How do t-distributions compare with the standard normal distribution?
They are symmetric and bell-shaped like it, but with wider tails.Topic 4.2, CED code 4.2.A.1
What is the standard error of a sample mean?
s divided by the square root of n.Topic 4.2, CED code 4.2.E.1
Which test is used for a population mean when the population standard deviation is unknown?
A one-sample t-test.Topic 4.4, CED code 4.4.A.1

Unit 5: Regression Analysis (10-20%)

What does a description of the association in a scatterplot include?
Form, direction, strength, and unusual features.Topic 5.1, CED code 5.1.B.1
What does the correlation r summarize?
The strength and direction of the linear association between two quantitative variables.Topic 5.2, CED code 5.2.A.1
What does a positive residual mean?
The model underpredicts the response.Topic 5.4, CED code 5.4.B.1
How is the least-squares regression line fit?
By minimizing the sum of the squared residuals.Topic 5.5, CED code 5.5.A.1
