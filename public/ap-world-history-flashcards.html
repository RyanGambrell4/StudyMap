Unit 1: The Global Tapestry (c. 1200 to c. 1450) (8-10%)

What happened to the economy of Song China?
It became increasingly commercialized while continuing to depend on free peasant and artisanal labor.Topic 1.1, CED code KC-3.3.III.A.i
What did Muslim states and empires encourage?
Significant intellectual innovations and transfers.Topic 1.2, CED code KC-3.2.II.A.i
How was Europe politically organized from c. 1200 to c. 1450?
It was politically fragmented, with decentralized monarchies, feudalism, and the manorial system.Topic 1.6, CED code KC-3.2.I.B.ii

Unit 2: Networks of Exchange (c. 1200 to c. 1450) (8-10%)

What environmental knowledge did Indian Ocean trade depend on?
Advanced knowledge of the monsoon winds.Topic 2.3, CED code KC-3.1.II.A.i
What did merchants set up in key places along trade routes?
Diasporic communities, where they introduced their own cultural traditions.Topic 2.3, CED code KC-3.1.III.B
Which West African empire's expansion facilitated Afro-Eurasian trade?
Mali.Topic 2.4, CED code KC-3.1.I.E.ii

Unit 3: Land-Based Empires (c. 1450 to c. 1750) (12-15%)

How did rulers of land-based empires legitimize their rule?
Through religious ideas, art, and monumental architecture.Topic 3.2, CED code KC-4.3.I.A
How did rulers of land-based empires generate revenue?
Through tribute collection, tax farming, and innovative tax-collection systems.Topic 3.2, CED code KC-4.3.I.D
What intensified the split between Sunni and Shi'a Islam?
Political rivalries between the Ottoman and Safavid empires.Topic 3.3, CED code KC-4.1.VI.ii
Where did Sikhism develop?
In South Asia, in a context of interactions between Hinduism and Islam.Topic 3.3, CED code KC-4.1.VI.iii

Unit 4: Transoceanic Interconnections (c. 1450 to c. 1750) (12-15%)

What resulted from Portuguese maritime development?
Increased travel to and trade with Africa and Asia.Topic 4.2, CED code KC-4.1.III.A
Which African states grew through maritime trade?
The Asante and the Kingdom of the Kongo.Topic 4.4, CED code KC-4.3.II.A.ii
What did European rulers use mercantilist policies for?
To expand and control their economies and claim overseas territories.Topic 4.5, CED code KC-4.1.IV.C

Unit 5: Revolutions (c. 1750 to c. 1900) (12-15%)

On what did people build a new sense of commonality, or nationalism?
Language, religion, social customs, and territory.Topic 5.2, CED code KC-5.3.II.ii
What did the factory system do?
It concentrated production in a single location and increased the specialization of labor.Topic 5.3, CED code KC-5.1.I.C
What did the "second industrial revolution" bring?
New methods of producing steel, chemicals, electricity, and precision machinery.Topic 5.5, CED code KC-5.1.I.E
What did U.S. and European influence in Asia lead to in Japan?
Internal reform that supported industrialization.Topic 5.6, CED code KC-5.2.II.A

Unit 6: Consequences of Industrialization (c. 1750 to c. 1900) (12-15%)

How did European states expand their empires in Africa?
Through both warfare and diplomacy.Topic 6.2, CED code KC-5.2.I.C
Where was economic imperialism primarily practiced?
In Asia and Latin America.Topic 6.5, CED code KC-5.2.I.E
How did receiving societies sometimes respond to immigrants?
With ethnic and racial prejudice, and with state attempts to restrict immigration.Topic 6.7, CED code KC-5.4.III.C

Unit 7: Global Conflict (c. 1900 to the present) (8-10%)

Which land-based empires collapsed after 1900?
The Ottoman, Russian, and Qing empires.Topic 7.1, CED code KC-6.2.I.A
How did governments mobilize populations for World War I, the first total war?
With political propaganda, art, media, and intensified forms of nationalism, in both home countries and colonies.Topic 7.3, CED code KC-6.2.IV.A.i
How did the Soviet government control its national economy?
Through the Five Year Plans, often implementing repressive policies.Topic 7.4, CED code KC-6.3.I.A.i

Unit 8: Cold War and Decolonization (c. 1900 to the present) (8-10%)

What military alliances did the Cold War produce?
NATO and the Warsaw Pact, along with nuclear proliferation and proxy wars.Topic 8.3, CED code KC-6.2.IV.D
How did China's communist government control its economy?
Through the Great Leap Forward.Topic 8.4, CED code KC-6.3.I.A.ii
What contributed to the end of the Cold War?
Advances in U.S. military and technology, and the Soviet Union's costly and ultimately failed invasion of Afghanistan, and public discontent and economic weakness in communist countries.Topic 8.8, CED code KC-6.2.IV.E

Unit 9: Globalization (c. 1900 to the present) (8-10%)

What did the Green Revolution and commercial agriculture do?
They increased productivity and sustained the Earth's growing population.Topic 9.1, CED code KC-6.1.I.B
What contributed to debates about climate change?
The release of greenhouse gases and pollutants into the atmosphere.Topic 9.3, CED code KC-6.1.II.B
Why was the United Nations formed?
With the stated goal of maintaining world peace and facilitating international cooperation.Topic 9.8, CED code KC-6.3.II.A
