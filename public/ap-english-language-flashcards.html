All 26 AP English Language flashcards

The full deck as text, grouped by unit. Each answer lists the CED topic and code it comes from.

Unit 1

What makes up the rhetorical situation?
Exigence, purpose, audience, context, and message.CED code RHS-1.A
What is exigence?
The part of a rhetorical situation that inspires, stimulates, provokes, or prompts a writer to create a text.CED code RHS-1.B
What is the purpose of a text?
What the writer hopes to accomplish with it. A text may have more than one purpose.CED code RHS-1.C
What does an audience share?
An audience has shared as well as individual beliefs, values, needs, and backgrounds.CED code RHS-1.D
What does the context of a text include?
The time, place, and occasion in which the writer creates it.CED code RHS-1.E
How do writers convey their positions?
Through one or more claims that require a defense.CED code CLE-1.A
Name types of evidence.
Facts, anecdotes, analogies, statistics, examples, details, illustrations, expert opinions, personal observations, personal experiences, testimonies, or experiments.CED code CLE-1.C

Unit 2

What do arguments use to persuade or motivate action?
Appeals, also called modes of persuasion.CED code RHS-1.H
When is evidence sufficient?
When its quantity and quality provide apt support for the argument.CED code CLE-1.H
What is a thesis?
The main, overarching claim a writer seeks to defend or prove using reasoning supported by evidence.CED code CLE-1.I

Unit 3

How do writers explain their reasoning?
Through commentary that connects chosen evidence to a claim.CED code REO-1.C
What does commentary do?
It explains the significance and relevance of evidence in relation to the line of reasoning.CED code REO-1.D
Name typical methods of development.
Narration, cause-effect, comparison-contrast, definition, and description.CED code REO-1.H
What must writers do when they use other people's intellectual property?
Acknowledge it through attribution, citation, or reference.CED code CLE-1.N

Unit 4

What does a conclusion do?
It brings the argument to a unified end and may present the thesis.CED code RHS-1.J

Unit 5

What are transitional elements?
Words, phrases, clauses, sentences, or paragraphs that create coherence among sentences, paragraphs, or sections.CED code REO-1.P
What two kinds of meaning do words have?
Connotative and denotative meanings.CED code STL-1.A

Unit 6

Position vs. perspective?
Sources may share a position on a subject yet come from different perspectives based on their backgrounds and interests.CED code CLE-1.R
What is tone?
The writer's attitude or feeling about a subject, conveyed through word choice and writing style.CED code STL-1.D
How do readers infer a writer's tone?
From the writer's word choice, especially the positive, negative, or other connotations of those words.CED code STL-1.E

Unit 7

Coordination vs. subordination?
Coordination shows balance or equality between ideas. Subordination shows imbalance or inequality.CED code STL-1.J-K
How can writers qualify an argument?
By using words, phrases, and clauses as modifiers to limit its scope.CED code CLE-1.X

Unit 8

Why do writers use comparisons such as similes, metaphors, analogies, or anecdotes?
To relate to an audience. An effective comparison must be shared and understood by the audience to advance the writer's purpose.CED code RHS-1.K
What makes up a writer's style?
The mix of word choice, syntax, and conventions the writer uses.CED code STL-1.Q

Unit 9

How do writers enhance their credibility when dealing with opposing arguments?
By refuting, rebutting, or conceding opposing arguments and contradictory evidence.CED code CLE-1.AA
Concede vs. rebut vs. refute?
Conceding accepts all or part of a competing claim. Rebutting offers a contrasting perspective or alternative evidence. Refuting uses evidence to show that all or part of a competing claim is invalid.CED code CLE-1.AB-AD

Source

College Board, AP English Language and Composition Course and Exam Description, Effective Fall 2024. Unit titles, exam weights and topic numbers come from this document. Each card quotes or closely paraphrases the essential knowledge statement named by its CED code; open the PDF and search the code to read the full statement.
