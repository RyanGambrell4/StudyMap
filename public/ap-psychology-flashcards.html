All 24 AP Psychology flashcards

The full deck as text, grouped by unit. Each answer lists the CED topic and code it comes from.

Unit 1: Biological Bases of Behavior (15-25%)

What research designs are used to study the effects of genes on behavior?
Twin studies, family studies, and adoption studies.Topic 1.1, CED code 1.1.A.3
What does the central nervous system include?
The brain and the spinal cord.Topic 1.2, CED code 1.2.A.1
Agonists vs. antagonists?
Agonists encourage neural firing. Antagonists inhibit neural firing.Topic 1.3, CED code 1.3.C.1
What does the brain stem, including the medulla, control?
Basic functioning such as breathing and heart rate.Topic 1.4, CED code 1.4.A.1
Which sense is not processed first in the thalamus?
Smell.Topic 1.6, CED code 1.6.D.1

Unit 2: Cognition (15-25%)

Bottom-up vs. top-down processing?
Bottom-up processing relies on external sensory information. Top-down processing relies on internal prior expectations.Topic 2.1, CED code 2.1.A.1
What is a prototype?
The ideal example for any given concept.Topic 2.2, CED code 2.2.A.1
Recall vs. recognition?
Recall is remembering without cues. Recognition relies on retrieval cues.Topic 2.6, CED code 2.6.A.1
What does the forgetting curve show?
Forgetting occurs rapidly after initial learning and levels off over time.Topic 2.7, CED code 2.7.A.1
What is the Flynn effect?
The general rise in IQ scores over time, due to societal factors such as higher SES, better health care, and better nutrition.Topic 2.8, CED code 2.8.C.1

Unit 3: Development and Learning (15-25%)

According to Piaget, how do children develop schemas?
Through assimilation and accommodation.Topic 3.4, CED code 3.4.A.1
What does the law of effect state?
Behaviors with reinforcing consequences are more likely to be repeated.Topic 3.8, CED code 3.8.A.1
What is insight learning?
When the solution to a problem occurs without any association, consequence, or model being present.Topic 3.9, CED code 3.9.B.1
What is latent learning?
Information learned without reinforcement.Topic 3.9, CED code 3.9.B.2

Unit 4: Social Psychology and Personality (15-25%)

Dispositional vs. situational attributions?
Dispositional attributions relate to internal qualities of others, such as intelligence or personality. Situational attributions relate to external factors.Topic 4.1, CED code 4.1.A.1
What is the mere exposure effect?
Repeated exposure to a stimulus over time can increase liking for it.Topic 4.1, CED code 4.1.C.1
What is belief perseverance?
When a belief persists even if evidence suggests it is not accurate.Topic 4.2, CED code 4.2.B.1
According to social-cognitive theory, what shapes personality?
Reciprocal determinism.Topic 4.5, CED code 4.5.A.1
Which hormones regulate hunger?
Ghrelin and leptin, which regulate feelings of hunger and satiety.Topic 4.6, CED code 4.6.B.1.i

Unit 5: Mental and Physical Health (15-25%)

What are the stages of the general adaptation syndrome?
Alarm reaction (fight-flight-freeze), then resistance, then exhaustion.Topic 5.1, CED code 5.1.C.1
Problem-focused vs. emotion-focused coping?
Problem-focused coping treats stress as a problem to solve. Emotion-focused coping manages emotional reactions to stress.Topic 5.1, CED code 5.1.D.1-2
What does the biopsychosocial model assume?
Any psychological problem potentially involves a combination of biological, psychological, and sociocultural factors.Topic 5.3, CED code 5.3.C.1
What characterizes bipolar disorders?
Periods of mania and periods of depression.Topic 5.4, CED code 5.4.D.1
What techniques do psychodynamic therapies use?
Free association and dream interpretation.Topic 5.5, CED code 5.5.D.1
