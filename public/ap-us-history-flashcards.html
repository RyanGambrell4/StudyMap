Unit 1: Period 1: 1491-1607 (4-6%)

What did the spread of maize cultivation into the present-day American Southwest support?
Economic development, settlement, advanced irrigation, and social diversification.Topic 1.2, CED code KC-1.1.I.A
What motivated European exploration and conquest in the Americas?
A search for new sources of wealth, economic and military competition, and a desire to spread Christianity.Topic 1.3, CED code KC-1.2.I.A
What was the encomienda system?
A system through which Spanish colonial economies marshaled Native American labor to support plantation agriculture and extract precious metals and other resources.Topic 1.5, CED code KC-1.2.II.B

Unit 2: Period 2: 1607-1754 (6-8%)

How did French and Dutch colonization differ from English colonization?
French and Dutch efforts involved relatively few Europeans and relied on trade alliances and intermarriage with American Indians. English efforts attracted comparatively large numbers of migrants.Topic 2.2, CED code KC-2.1.I.B-C
What did the Chesapeake and North Carolina colonies grow for export?
Tobacco, a labor-intensive product.Topic 2.3, CED code KC-2.1.II.A
What led the Spanish to accommodate some Native practices?
American Indian resistance, particularly after the Pueblo Revolt.Topic 2.5, CED code KC-2.1.III.F

Unit 3: Period 3: 1754-1800 (10-17%)

What was the result of Britain's victory over France in the Seven Years' War?
A major expansion of British territory at tremendous expense, which set the stage for imperial efforts to raise revenue.Topic 3.2, CED code KC-3.1.I.B
What kind of central government did the Articles of Confederation create?
A central government with limited power.Topic 3.7, CED code KC-3.2.II.B
What did the Northwest Ordinance do?
It set the process for admitting new states, and it promoted public education, the protection of private property, and a ban on slavery in the Northwest Territory.Topic 3.7, CED code KC-3.3.I.C
What did Washington's Farewell Address warn against?
Political factions and permanent foreign alliances.Topic 3.10, CED code KC-3.3.II.C

Unit 4: Period 4: 1800-1848 (10-17%)

What did early Supreme Court decisions establish?
The primacy of the judiciary in interpreting the Constitution, and that federal laws took precedence over state laws.Topic 4.2, CED code KC-4.1.I.B
What was the effect of the Missouri Compromise?
It only temporarily stemmed growing tensions between opponents and defenders of slavery.Topic 4.3, CED code KC-4.3.II.C
Which innovations drove the market revolution?
Textile machinery, steam engines, interchangeable parts, the telegraph, and agricultural inventions.Topic 4.5, CED code KC-4.2.I.B
Where did the women's rights movement express its ideals?
At the Seneca Falls Convention.Topic 4.11, CED code KC-4.1.III.C

Unit 5: Period 5: 1844-1877 (10-17%)

What did advocates of annexing western lands argue?
That Manifest Destiny and the superiority of American institutions compelled the United States to expand.Topic 5.2, CED code KC-5.1.I.B
What nativist movement arose in the 1840s and 1850s?
A strongly anti-Catholic movement aimed at limiting new immigrants' political power and cultural influence.Topic 5.5, CED code KC-5.1.II.B
How did the Emancipation Proclamation change the Civil War?
Lincoln began the war to preserve the Union. The Proclamation reframed the purpose of the war and helped prevent the Confederacy from gaining full diplomatic support from European powers.Topic 5.9, CED code KC-5.3.I.B
What did the 13th, 14th, and 15th Amendments do?
The 13th abolished slavery. The 14th and 15th granted African Americans citizenship, equal protection under the laws, and voting rights.Topic 5.10, CED code KC-5.3.II.A

Unit 6: Period 6: 1865-1898 (10-17%)

What did Plessy v. Ferguson uphold?
Racial segregation (Jim Crow).Topic 6.4, CED code KC-6.3.II.C
How did business leaders seek increased profits in the Gilded Age?
By consolidating corporations into large trusts and holding companies.Topic 6.6, CED code KC-6.1.I.D

Unit 7: Period 7: 1890-1945 (10-17%)

What did victory in the Spanish-American War bring the United States?
Island territories in the Caribbean and the Pacific.Topic 7.3, CED code KC-7.3.I.C
What did the Senate refuse to do after World War I?
Ratify the Treaty of Versailles or join the League of Nations.Topic 7.5, CED code KC-7.3.II.C
Which 1920s movement expressed ethnic and regional identity?
The Harlem Renaissance.Topic 7.8, CED code KC-7.2.I.B
What did the New Deal aim to do?
Use government power to provide relief to the poor, stimulate recovery, and reform the economy.Topic 7.10, CED code KC-7.1.III.A

Unit 8: Period 8: 1945-1980 (10-17%)

How did the Cold War fluctuate?
Between periods of direct and indirect military confrontation and periods of mutual coexistence (detente).Topic 8.2, CED code KC-8.1.I.C
What spurred economic growth after 1945?
A burgeoning private sector, federal spending, the baby boom, and technological developments.Topic 8.4, CED code KC-8.3.I.A
What did the Vietnam War inspire at home?
Sizable and passionate antiwar protest.Topic 8.8, CED code KC-8.1.II.B

Unit 9: Period 9: 1980-Present (4-6%)

What contributed to the end of the Cold War?
Increased U.S. military spending, Reagan's diplomatic initiatives, and political changes and economic problems in Eastern Europe and the Soviet Union.Topic 9.3, CED code KC-9.3.I.B
How did employment shift after 1980?
Service-sector jobs increased, manufacturing jobs decreased, and union membership declined.Topic 9.4, CED code KC-9.2.I.C
What questions did the war on terrorism raise?
Questions about the protection of civil liberties and human rights.Topic 9.6, CED code KC-9.3.II.B
