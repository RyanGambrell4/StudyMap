Unit 1: Limits and Continuity (10-15%)

Name three ways a limit might not exist.
The function is unbounded, the function oscillates near the value, or the left-hand limit does not equal the right-hand limit.Topic 1.3, CED code LIM-1.C.4
What are the types of discontinuities?
Removable discontinuities, jump discontinuities, and discontinuities due to vertical asymptotes.Topic 1.10, CED code LIM-2.A.1
When is a function f continuous at x = c?
When f(c) exists, the limit of f(x) as x approaches c exists, and the two are equal.Topic 1.11, CED code LIM-2.A.2
What do limits at infinity describe?
End behavior.Topic 1.15, CED code LIM-2.D.4

Unit 2: Differentiation: Definition and Fundamental Properties (10-15%)

Graphically, what is the derivative of a function at a point?
The slope of the line tangent to the graph of the function at that point.Topic 2.2, CED code CHA-2.C.1
If f is differentiable at a point, what follows?
f is continuous at that point. A continuous function may still fail to be differentiable.Topic 2.4, CED code FUN-2.A.1-2

Unit 3: Differentiation: Composite, Implicit, and Inverse Functions (5-10%)

What does the chain rule differentiate?
Composite functions.Topic 3.1, CED code FUN-3.C.1
What is the basis for implicit differentiation?
The chain rule.Topic 3.2, CED code FUN-3.D.1
How is the second derivative of f produced?
By differentiating f', provided the derivative of f' exists.Topic 3.6, CED code FUN-3.F.1

Unit 4: Contextual Applications of Differentiation (10-15%)

What is the unit of f'(x)?
The unit for f divided by the unit for x.Topic 4.1, CED code CHA-3.A.3
What is the basis for differentiating the variables in a related rates problem?
The chain rule.Topic 4.4, CED code CHA-3.D.1
What is the tangent line to a graph, in terms of approximation?
The graph of a locally linear approximation of the function near the point of tangency.Topic 4.6, CED code CHA-3.F.1
Which indeterminate forms can L'Hospital's Rule evaluate?
0/0 and infinity/infinity.Topic 4.7, CED code LIM-4.A.2

Unit 5: Analytical Applications of Differentiation (15-20%)

What does the Mean Value Theorem guarantee?
If f is continuous on [a, b] and differentiable on (a, b), there is a point in (a, b) where the instantaneous rate of change equals the average rate of change over [a, b].Topic 5.1, CED code FUN-1.B.1
What is a critical point?
A point in the domain where the first derivative equals zero or fails to exist.Topic 5.2, CED code FUN-1.C.2
Where can absolute extrema on a closed interval occur?
Only at critical points or at endpoints.Topic 5.5, CED code FUN-4.A.3
When is the graph of a function concave up?
On an open interval where the function's derivative is increasing.Topic 5.6, CED code FUN-4.A.4

Unit 6: Integration and Accumulation of Change (15-20%)

What does the area between a rate-of-change graph and the x-axis give?
The accumulation of change.Topic 6.1, CED code CHA-4.A.1
Name the Riemann-type approximations in the CED.
Left, right, and midpoint Riemann sums, and the trapezoidal sum.Topic 6.2, CED code LIM-5.A.2
What is an antiderivative of f?
A function g whose derivative is f.Topic 6.8, CED code FUN-6.B.1
What must change when you use substitution on a definite integral?
The limits of integration.Topic 6.9, CED code FUN-6.D.2

Unit 7: Differential Equations (5-10%)

What is a slope field?
A graphical representation of a differential equation on a finite set of points in the plane.Topic 7.3, CED code FUN-7.C.1
General solution vs. particular solution?
A general solution may describe infinitely many solutions. Only one particular solution passes through a given point.Topic 7.7, CED code FUN-7.E.1
Which differential equation models "the rate of change of a quantity is proportional to the size of the quantity"?
dy/dt = ky.Topic 7.8, CED code FUN-7.F.2

Unit 8: Applications of Integration (10-15%)

What do the definite integrals of velocity and of speed represent?
The integral of velocity is displacement. The integral of speed is total distance traveled.Topic 8.2, CED code CHA-4.C.1
What does the definite integral of a rate of change give?
The net change of that quantity over the interval.Topic 8.3, CED code CHA-4.D.2
When is the washer method used?
For volumes of solids of revolution whose cross sections are ring shaped.Topic 8.11, CED code CHA-5.C.3
