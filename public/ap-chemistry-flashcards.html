All 31 AP Chemistry flashcards

The full deck as text, grouped by unit. Each answer lists the CED topic and code it comes from.

Unit 1: Atomic Structure and Properties (7-9%)

What does Avogadro's number connect?
The number of moles in a pure sample of a substance and the number of constituent particles of that substance (6.022 x 10^23 per mole).Topic 1.1, CED code 1.1.A.2
What is the law of definite proportions?
The ratio of the masses of the constituent elements in any pure sample of a compound is always the same.Topic 1.3, CED code 1.3.A.2
What does photoelectron spectroscopy (PES) measure?
The energies of the electrons in a given shell.Topic 1.6, CED code 1.6.A.1

Unit 2: Compound Structure and Properties (7-9%)

How does electronegativity trend on the periodic table?
It increases from left to right across a period and decreases down a group.Topic 2.1, CED code 2.1.A.1
How is metallic bonding represented?
As an array of positive metal ions surrounded by delocalized valence electrons, a "sea of electrons."Topic 2.4, CED code 2.4.A.1
What is VSEPR theory based on?
Coulombic repulsion between electrons.Topic 2.7, CED code 2.7.A.1

Unit 3: Properties of Substances and Mixtures (18-22%)

What causes London dispersion forces?
Coulombic interactions between temporary, fluctuating dipoles.Topic 3.1, CED code 3.1.A.1
In a mixture of gases, what does the partial pressure of each gas depend on?
The pressure of each component is independent of the other components.Topic 3.4, CED code 3.4.A.2
Which substances tend to be miscible?
Substances with similar intermolecular interactions.Topic 3.10, CED code 3.10.A.1
In the Beer-Lambert law, with path length and wavelength held constant, what is absorbance proportional to?
Only the concentration of the absorbing species.Topic 3.13, CED code 3.13.A.2

Unit 4: Chemical Reactions (7-9%)

What is a titration used for?
To determine the amount of an analyte in solution.Topic 4.6, CED code 4.6.A.1
What does an oxidation-reduction (redox) reaction involve?
The transfer of one or more electrons between chemical species, shown by changes in oxidation numbers.Topic 4.7, CED code 4.7.A.2
Bronsted-Lowry acid vs. base?
An acid is a proton donor. A base is a proton acceptor.Topic 4.8, CED code 4.8.A.1

Unit 5: Kinetics (7-9%)

For a first-order reaction, which plot is linear?
The natural log of the reactant concentration vs. time.Topic 5.3, CED code 5.3.A.2
What do successful collisions need?
Sufficient energy to overcome the activation energy barrier, and the proper orientation.Topic 5.5, CED code 5.5.A.2
What happens to the net concentration of a catalyst in a reaction mechanism?
It stays constant, though the catalyst may be consumed and regenerated.Topic 5.11, CED code 5.11.A.2

Unit 6: Thermochemistry (7-9%)

How do the particles of a warmer body compare with those of a cooler body?
Particles in the warmer body have greater average kinetic energy.Topic 6.3, CED code 6.3.A.1
What does the first law of thermodynamics state?
Energy is conserved in chemical and physical processes.Topic 6.4, CED code 6.4.A.2
What happens to the enthalpy change when a reaction is reversed?
Its magnitude stays the same, but its sign is reversed.Topic 6.9, CED code 6.9.B.2

Unit 7: Equilibrium (7-9%)

Which substances are left out of the reaction quotient Q?
Substances whose concentrations are independent of the amount present, such as pure solids and liquids.Topic 7.3, CED code 7.3.A.2
What happens to K when a reaction is reversed?
K is inverted.Topic 7.6, CED code 7.6.A.1
Which stress changes the equilibrium constant K itself?
A change in temperature. Changes in concentration alter only Q.Topic 7.10, CED code 7.10.A.2
What is the common-ion effect?
A salt is less soluble in a solution that already contains one of its ions.Topic 7.12, CED code 7.12.A.1

Unit 8: Acids and Bases (11-15%)

What is Kw at 25 degrees C?
[H3O+][OH-] = 1.0 x 10^-14.Topic 8.1, CED code 8.1.A.2
How do strong acids behave in water?
They ionize completely. Examples are HCl, HBr, HI, HClO4, H2SO4, and HNO3.Topic 8.2, CED code 8.2.A.1
At the equivalence point of a monoprotic acid-base titration, what is true?
The moles of titrant added equal the moles of analyte.Topic 8.5, CED code 8.5.A.2
What is a buffer?
A solution with a large concentration of both members of a conjugate acid-base pair.Topic 8.8, CED code 8.8.A.1

Unit 9: Thermodynamics and Electrochemistry (7-9%)

When does entropy increase?
When matter becomes more dispersed, or when energy becomes more dispersed.Topic 9.1, CED code 9.1.A.1-2
What is kinetic control?
When a thermodynamically favored process does not proceed at a measurable rate, often because of a high activation energy.Topic 9.4, CED code 9.4.A.2
Under standard conditions, what does a negative standard Gibbs free energy change mean for K?
Products are favored at equilibrium, so K > 1.Topic 9.5, CED code 9.5.A.1
Galvanic cell vs. electrolytic cell?
Galvanic cells involve a thermodynamically favored reaction. Electrolytic cells involve a reaction that is not thermodynamically favored.Topic 9.8, CED code 9.8.A.2
